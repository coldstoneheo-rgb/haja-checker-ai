## 1. 누락 작업 (즉시 처리 필요)

### 🔴 1-1. Gemini API 키 미등록 → AI 분석 검증 불가

**현황**:
- `lib/ai/index.ts`의 `createAnalyzer()`는 production에서 `GEMINI_API_KEY` 누락 시 **500 에러**를 던진다 (`AiAnalyzerError`)
- 현재 Vercel 배포는 키가 등록돼 있지 않아 `/api/analyze` 호출이 모두 실패한다
- D-7(AI 연동) 단계가 **코드만 작성됐고 실제 API 호출은 한 번도 검증되지 않은 상태**

**영향**:
- D-2 모의점검 시나리오 3, 4, 7번이 통과 불가 (시나리오 3-7 "분석 완료 대기 → 분석 결과 카드 표시" 단계에서 실패)
- 실제 점검일(5/11)에 AI 분석 기능이 작동하지 않을 위험

**조치 계획**:
1. **(사용자)** Google AI Studio에서 Gemini API 키 발급
2. **(사용자)** Vercel 대시보드 → Project → Settings → Environment Variables에서 `GEMINI_API_KEY` 등록 (Production + Preview 모두)
3. **(사용자)** Preview 브랜치 자동 재배포 확인
4. **(테스트)** D-2 시나리오 3 실행 → 실제 AI 응답 검증
5. **(검증 항목)**:
   - [ ] 응답 시간 30초 이내
   - [ ] 한국어 출력 정상
   - [ ] 위험도/하자유형/수리난이도 합리적
   - [ ] 비용 모니터링 (Google AI Studio dashboard)
