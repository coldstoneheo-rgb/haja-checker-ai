# D-2 실기기 모의점검 시나리오

**목적**: 실제 점검일(D-0) 전에 실기기에서 앱 전체 흐름을 검증한다.  
**소요 시간**: 약 60–90분  
**기기**: iOS iPhone (Safari) + Android (Chrome) 중 최소 1대 이상

---

## 사전 준비

### 기기 준비
- [ ] Vercel 배포 URL을 Safari/Chrome에서 접속
- [ ] 홈 화면에 추가 (A2HS) — iOS: 공유→홈 화면에 추가 / Android: 메뉴→앱 설치
- [ ] 홈 화면 아이콘으로 앱 실행 확인 (브라우저 주소창 없이 뜨면 정상)
- [ ] `GEMINI_API_KEY`가 Vercel에 설정돼 있는지 확인

### 모의 점검 공간
- 실제 집 또는 방 한 칸을 점검 대상으로 지정한다
- 인위적 하자 상황을 만들 필요는 없다 — 정상 상태 사진도 시나리오에 포함

---

## 시나리오 1: 세션 생성

**목표**: 세션이 올바르게 생성되고 체크리스트가 seed 28개 항목으로 초기화된다.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 1-1 | 앱 실행 → "새 점검 시작" 탭 | 세션 생성 폼이 열린다 |
| 1-2 | 단지명·동·호수 입력 (예: 테스트단지 / 101동 / 1001호) | 입력값이 유지된다 |
| 1-3 | 점검일 선택 (오늘 날짜) | 날짜 선택이 동작한다 |
| 1-4 | "점검 시작" 버튼 탭 | 세션 대시보드로 이동한다 |
| 1-5 | 대시보드 진행률 확인 | 0 / 28 (0%) 표시 |
| 1-6 | 앱 종료 후 재실행 | 세션이 그대로 남아 있다 (IndexedDB 유지) |

---

## 시나리오 2: 체크리스트 점검 — 정상 항목

**목표**: 양호 항목을 사진 촬영과 함께 기록하고 진행률이 올라간다.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 2-1 | "체크리스트" 탭 → 현관 영역 탭 | 현관 3개 항목이 보인다 |
| 2-2 | "현관문 개폐 및 문틀 상태" 항목 탭 | 항목 상세 화면이 열린다 |
| 2-3 | 📷 카메라 버튼 탭 → 현관문 전체 사진 촬영 | 사진 권한 요청 팝업이 뜬다 |
| 2-4 | 권한 허용 → 촬영 완료 | 썸네일이 그리드에 표시된다 |
| 2-5 | 추가로 문틀 근접 사진 1장 더 촬영 | 2장 썸네일 모두 표시 |
| 2-6 | 상태를 "양호"로 변경 | 항목에 ✅ 표시, 상태가 GOOD으로 저장 |
| 2-7 | 대시보드 진행률 확인 | 1 / 28 완료로 증가 |

**iOS 특이 확인**: 세로로 찍은 사진이 회전 없이 올바른 방향으로 표시되는지 확인 (EXIF orientation 보정).

---

## 시나리오 3: 체크리스트 점검 — 하자 의심 항목

**목표**: 실제 의심 부위를 촬영하고 AI 분석을 받아 하자를 등록한다.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 3-1 | 거실 영역 → "벽지·천장 마감 상태" 항목 탭 | 항목 상세 화면 |
| 3-2 | 사진 3종 촬영 가이드 확인 | ① 전체 위치 ② 부위 포함 ③ 클로즈업 안내 표시 |
| 3-3 | 벽지 이음부 또는 천장 사진 2장 촬영 | 썸네일 표시 |
| 3-4 | 메모 입력: "도배 이음부 들뜸 의심" | 메모가 저장된다 |
| 3-5 | 상태를 "의심"으로 변경 | 항목에 🟡 표시 |
| 3-6 | "분석" 탭 → 해당 항목의 "AI 분석 실행" 버튼 탭 | 로딩 스피너 표시 |
| 3-7 | 분석 완료 대기 (최대 30초) | 분석 결과 카드 표시 |
| 3-8 | 결과 확인: 하자 유형·위험도·수리 난이도·요청 문구 | 한국어로 정상 출력 |
| 3-9 | 상태를 "하자"로 변경 → 저장 | DEFECT 상태로 변경 |

---

## 시나리오 4: 직접 하자 등록

**목표**: 체크리스트 항목과 무관한 하자를 직접 등록하고 ID가 자동 부여된다.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 4-1 | "하자 등록" 탭 → "+ 직접 등록" 버튼 탭 | 하자 등록 폼 |
| 4-2 | 영역: 주방 / 위치: 싱크대 하부 / 유형: 누수 선택 | 폼 필드 동작 |
| 4-3 | 사진 2장 촬영 | 썸네일 표시 |
| 4-4 | 메모 입력: "싱크대 배관 연결부에서 물기 발견" | 저장 |
| 4-5 | "등록" 버튼 탭 | D-YYYYMMDD-001 형식 ID 자동 부여 확인 |
| 4-6 | AI 분석 실행 | 누수(LEAK) 유형 분석 결과 확인 |
| 4-7 | 두 번째 직접 하자 등록 | ID가 -002로 증가하는지 확인 |

---

## 시나리오 5: 오프라인 동작

**목표**: 네트워크 없이도 기록 데이터가 유지되고 안내 메시지가 표시된다.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 5-1 | 기기 비행기 모드 ON | — |
| 5-2 | 앱 강제 종료 후 재실행 | 홈 화면에서 앱이 정상 로드된다 (SW 캐시) |
| 5-3 | 세션 목록 접근 | 기존 세션이 보인다 |
| 5-4 | 체크리스트 → 항목 상태 "양호"로 변경 | 상태 변경이 저장된다 (IndexedDB는 오프라인 정상) |
| 5-5 | AI 분석 실행 시도 | "오프라인" 안내 메시지 또는 네트워크 오류 표시 |
| 5-6 | 비행기 모드 OFF | 앱 새로고침 없이 분석 재시도 가능한지 확인 |

---

## 시나리오 6: 카메라 권한 거부

**목표**: 카메라 권한 거부 시 안내가 표시되고 앱이 중단되지 않는다.

> iOS Safari에서만 테스트 가능. Android는 권한 거부 후 재요청 흐름이 다름.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 6-1 | iOS: 설정 → Safari → 카메라 "허용 안 함" 설정 | — |
| 6-2 | 앱에서 카메라 버튼 탭 | 권한 거부 에러 메시지 + 기기 설정 안내 표시 |
| 6-3 | 갤러리에서 사진 업로드 시도 | 파일 선택 팝업이 열린다 (대안 경로 동작) |
| 6-4 | 설정에서 카메라 권한 복구 | 다시 카메라 촬영 가능 |

---

## 시나리오 7: 보고서 생성 및 출력

**목표**: 3개 이상의 하자를 포함한 세션에서 보고서가 정상 출력된다.

*(시나리오 2–4를 먼저 완료한 상태에서 진행)*

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 7-1 | "보고서" 탭 탭 | 세션 요약 + 하자 목록이 표시된다 |
| 7-2 | 보고서 내용 스크롤 확인 | 영역별 점검 결과, 하자 카드, AI 분석 요약 표시 |
| 7-3 | "PDF 출력" 버튼 탭 | 인쇄 미리보기 팝업 열림 |
| 7-4 | 미리보기에서 레이아웃 확인 | 한국어 폰트 정상, 페이지 분리 자연스러움 |
| 7-5 | 실제 PDF로 저장 또는 인쇄 취소 | — |
| 7-6 | "JSON 내보내기" 버튼 탭 | `.json` 파일 다운로드됨 |
| 7-7 | JSON 파일 내용 확인 | session, defects, analyses, checklistItems 키 포함 |

---

## 시나리오 8: 복수 세션

**목표**: 세션이 독립적으로 저장되고 전환이 정상 동작한다.

| 단계 | 동작 | 확인 사항 |
|------|------|-----------|
| 8-1 | 새 세션 생성 (다른 단지명) | 두 번째 세션 대시보드 열림 |
| 8-2 | 이 세션에서 항목 1개 "양호" 처리 | — |
| 8-3 | 세션 목록으로 이동 | 두 세션이 독립적으로 표시됨 |
| 8-4 | 첫 번째 세션으로 전환 | 진행 상태가 그대로 유지됨 |

## 완료 기준

다음을 모두 만족하면 D-2 통과로 간주한다:

- [ ] 세션 생성 → 체크리스트 28항목 초기화 정상
- [ ] 사진 촬영 → 썸네일 표시 → 방향 정상 (iOS EXIF 확인)
- [ ] 항목 상태 변경 → 대시보드 진행률 실시간 반영
- [ ] AI 분석 실행 → 30초 이내 결과 수신
- [ ] 직접 하자 등록 → D-YYYYMMDD-NNN ID 자동 부여
- [ ] 오프라인 상태에서 앱 로드 + 기존 데이터 열람 가능
- [ ] PDF 보고서 인쇄 미리보기 정상 (한국어 깨짐 없음)
- [ ] JSON export 파일 다운로드 + 내용 정합성 확인
- [ ] 치명·높음 심각도 이슈 없음
